# 开始使用 Psychology in Quotes

**适用对象：**心理学书籍读者、心理学专业人员、学生、教师，以及需要引用文字和出处的作者。

**开始体验：**[Telegram](https://t.me/DET_psy_in_quotes_bot) · [官方网站](https://detai-x.com/zh/technology/platform/psychology-in-quotes)。

## 1. 先体验，再按需创建 Account

打开 [Telegram 机器人](https://t.me/DET_psy_in_quotes_bot)，发送 `/start`，或从[网站公共目录](https://detai-x.com/zh/technology/platform/psychology-in-quotes)开始。浏览已发布的语录、出处和现成译文**无需 DETai Account**。公开图片上的水印属于正常的预览机制。

**Public 访客模式：**提供收藏夹和限时的个人水印卡片，创建次数及保存期限受到限制。体验周期结束后，可能可以再次尝试。实际访客限额请以运行中的机器人为准。Free / Plus / Pro 的[动态比较表在网站上](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)。

**何时需要 DETai Account：**如果希望超过访客期限后继续保留作品、获取无水印 PNG、使用永久收藏、制作 Stories 或通过 PiQ 发布内容，就需要账户。Free 账户免费；Plus/Pro 提供扩展功能。

1. 在 PiQ 的绑定账户提示中选择 **“打开 DETai Hub”**。仅打开 Hub 并不会自动注册或绑定账户。
2. 如果 Telegram 已绑定 DETai Account，Hub 会显示现有账户；否则可选择**直接在 Hub 创建账户**，或**连接先前在网站创建的账户**。
3. 对于已有账户，先登录 [DETai 账户中心](https://detai-x.com/zh/account)，选择“连接 Telegram”，通过 Hub 提供的安全一次性链接完成验证。仅登录网站不足以完成绑定，也无需重复创建账户。
4. 返回 PiQ：**下次正常操作会自动检查绑定状态**，符合条件的访客数据随后可能转移至永久收藏。“检查连接”可立即刷新页面，但不是必经步骤。接着打开“设置”→“我的订阅”：免费 Account 对应 Free，而不是 Plus 或 Pro。

首次跳转时，Hub 可以接收 **PiQ 的界面语言**。若 Hub 已保存自己的语言偏好，则优先使用已有设置。这不会改变语录的文本语言、译文语言或 Account 的个人资料语言。

**Public 为访客；Free 为拥有持久统一身份的参与者；Plus/Pro 为获得更高套餐权限的参与者。**这些仅是交互层级，不是专业资质证明，也不代表同意接收营销消息。

[查看网站上的最新套餐、功能与限额 →](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)

## 2. 创建自己的语录

在机器人中选择**“✨ 创建语录”**。填写语录文字、作者、来源书名，以及可用的页码与版本信息。核对文字语言和卡片样式，按创建向导操作，直到看到保存成功的确认。

新建语录会出现在**“📚 我的合集”→“✍️ 我的语录”**，即使尚未发布到公共目录。对于访客，这是一项**临时且未经审核的成果**；若未验证 Account 并通过规定的审查，不得进入公共目录。拥有 Account 的作者可以获取自己已生成的无水印图片，**即使在 Free 层级也不会消耗获取其他语录的额度**。

如果操作中断，请使用继续现有草稿的按钮。访客只能保留一个有效且有期限的项目；确切失效日期由机器人显示。不要为了保险而重复创建。当前 PNG 缺失时，请查看[故障排查说明](help-and-troubleshooting.md#piq-image-not-ready)。

## 3. 查找并获取他人的语录

1. 打开网站或机器人中的**“🌐 语录目录”**。
2. 找到语录，连同作者和出处一起阅读。现成译文可能以**带水印的预览**形式出现。
3. **“⭐ 收藏”**只保存书签，不会提供无水印文件。访客收藏限制以机器人提示为准。
4. **“📥 获取语录”**是一项需单独确认并受每周限额约束的操作，会将**一条语录（`quoteId`）**关联到你的 Account。
5. 打开**“📚 我的合集”→“📚 已获取的语录”**，选择有权限的语言，如有需要下载无水印图片。

在 **Free** 层级，获取操作只锁定一个选定语言。**Plus/Pro** 允许使用已获取语录的全部已生成且获准使用的语言版本，无需重复消耗获取额度。再次下载已授权文件或选择标准样式均不消耗新的获取次数。

## 4. 发布语录或创建 Stories

首先将 Telegram 与 DETai Account 绑定。对自己的语录或此前已获取的语录选择发布或 Stories。**他人的语录必须先获取才能发布**，自己的语录不受此要求限制。随后选择已准备好的版本、已连接的频道，并确认操作。发布和 Stories **分别计入不同的限额**。

发送可能处于 `pending`、`failed` 或 `uncertain` 状态。如果没有明确结果，**不要盲目重复发送**。请打开**“我的发布记录”**核对结果。

## 5. 常用功能在哪里？

| 需求 | 路径 |
| --- | --- |
| 切换界面语言 | 设置 → 界面语言 |
| 查看限额 | 设置 / 我的权限 |
| 查找自己创建的内容 | 我的收藏 → 我的语录 |
| 查找已获取的内容 | 我的收藏 → 已获取 |
| 查看发送成功或失败记录 | 我的发布记录 |
| 切换已获取语录的语言 | 已获取 → Language（取决于套餐） |
| 理解提示或截图 | [常见问题与故障排查](help-and-troubleshooting.md) |
