# PiQ 收藏、语言与套餐

**更新日期：2026 年 10 月 30 日。**本页解释收藏体系和权限层级，**不复制静态的套餐与额度表**。Free / Plus / Pro 的最新功能和限额由 PiQ 产品政策确定，并显示在[官方网站的动态套餐对比表](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)中。个人剩余额度、额外权限与有效套餐请到“我的权限”查看。

## 访客、参与者与订阅者是不同状态

- **Public：**尚未拥有统一 DETai Account 的访客。可以查看公共目录、带水印的译文，保存少量访客收藏，并在相应功能已部署的机器人版本中体验临时引言卡片。
- **Free：**拥有免费 DETai Account 的参与者，享有持久的个人 PiQ 空间及基础权限、限额。Telegram 与账户的绑定需要单独验证。
- **Plus / Pro：**拥有该产品扩展权限的参与者。**仍属于同一生态系统的参与者**，不是另一种会员身份。Free 用户无需升级付费套餐也能参与 DETai 的共同用户空间。

**先体验，再按需创建 Account。**[在网站比较 Free / Plus / Pro](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)。打开账户中心或完成绑定，并不表示订阅营销消息，也不会未经用户同意发布私人引言。

**关于访客模式：**收藏、临时卡片和可重复的体验周期已在 [PiQ PR #37](https://github.com/DETai-org/psychology-in-quotes/pull/37) 中实现。当前限制由产品实际界面展示；合并 PR 本身不能证明相关功能已部署到某个机器人。

## 必须区分的术语 {#piq-collection-terms}

- **我的引言：**由你创建的记录，无论是否通过公开审核。所有者可以使用当前已生成的个人 PNG，无需再次执行“获取”操作。
- **已获取：**从目录中获取并经确认后关联到 DETai Account 的他人引言。
- **收藏夹：**只保存书签，不会去除水印，也不授予下载无水印文件的权利。
- **我的发布记录：**通过 PiQ 实际发送内容的历史。制作 Stories 本身不代表已向外部发布。
- **获取：**对每个 Account 和 **`quoteId`** 只执行一次，而不是按 PNG、语言、修订版或模板分别计费。
- **下载：**领取已获准使用的文件，本身不意味着再次购买或获取引言。
- **预览：**供浏览使用的带水印图片。

## 最新套餐与限额

**[在 PiQ 官方网站查看最新 Free / Plus / Pro 对比](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)。**

网站上的对比表通过 API 读取实际生效的产品政策。此处**有意不填写固定数字**，无论是引言获取次数、发布次数、Stories、语言、频道、说明文字模板、BrandKit 还是其他套餐功能；否则公开文档可能与真实应用不一致。

请在[“我的权限”](https://detai-x.com/zh/account/products/psychology-in-quotes#piq-access)查看个人权限和剩余额度。消耗型操作的额度可能在结果确认前被预留，因此剩余数量应以应用实际显示为准。获取他人的引言、发布内容和创建 Stories 是三种独立操作；创建自己的引言不等于获取他人的引言。

## 语言与订阅变更

- 目录中已发布的现成译文可以通过**带水印的预览**阅读。
- 获取他人引言后，该引言的使用权关联至 Account。哪些语言可下载无水印文件，由当前权限及[网站公布的政策](https://detai-x.com/zh/technology/platform/psychology-in-quotes#piq-plans)决定。
- 再次下载已授权文件不会重复消耗“获取”额度。仅提供已生成并获准使用的版本。
- 降级套餐后，已获取的引言仍保留在收藏中。此前确认的语言权限按政策继续保留；是否可以使用新的附加语言由当前套餐决定。
- 对于已保存到个人设备的文件，PiQ 无法在物理上收回。但如果材料被删除或撤回，后续可能无法再从服务下载。
- 切换**界面语言**不会改变获取权限。

**需要区分三种语言：**提交文字片段的语言、原著语言（如已知），以及当前查看版本的语言。不能仅根据作者国籍推断原著语言。

## 法律说明

获取一条引言仅意味着获得**使用 PiQ 对应功能的权限**，并不意味着取得文学作品、他人译文或书籍的著作权。必须尊重作者署名、第三方权利和发布条款。如果来源存在争议，材料可能被下架。
