# ΨTunes 中的播客

[← ΨTunes](index.md)

**播客**是一种独立材料，可以有标题、文本版本以及音频版本。多期节目可以组成系列，但每期仍保留自己的标识和播放位置。

> **状态：**播客目录和个人制作功能正在开发。是否开放、配额及费用以正式提供时的产品界面为准。

**DETai 播客**由编辑团队准备。加入系列并不等于自动公开发布。**个人播客**以用户有权使用的文本为起点；导入文本与制作音频是两个独立步骤。播客配额与图书选择配额可能分别计算。

系列便于按顺序探索同一主题。更名和翻译不应将书签指向另一部作品。将节目加入收藏也不等于已经取得收听权限。只有在产品明确启用时，才能共享或交换私人材料。
