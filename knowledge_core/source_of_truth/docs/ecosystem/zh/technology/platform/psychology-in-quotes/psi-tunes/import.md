# 导入图书或播客

[← ΨTunes](index.md)

**导入**是将您有权使用的文档转成个人文本版本的过程。提取完成后，应检查书名、作者、语言、章节顺序及正文开头和结尾。

> **可用性：** 此流程属于开发中的 ΨTunes。实际支持的格式、大小和权限限制以应用界面为准。

## 文件格式

- **TXT：**检查编码、段落和标题。
- **FB2 / FB2.ZIP：**检查章节结构；ZIP 中应只有一份 FB2 文档。
- **EPUB：**检查阅读顺序和章节分界。
- **带文字层的 PDF：**检查多栏、表格和段落顺序。扫描 PDF 需要事先进行文字识别。

## 操作流程

1. 在个人资料库中选择可用的导入方式，可从设备或通过 Telegram 机器人提交。
2. 检查提取后的文本、元数据、语言和章节，确认前修正问题。
3. 确认文本版本。若修改原文，可能需要创建新版本，以保留旧书签的准确指向。
4. 如账户有权制作音频，选择语言和声音、试听样本，并在下单前确认页面显示的条件和费用。
5. 音频准备完成且拥有访问权限后，从资料库打开。

个人导入不会自动公开发布，上传文件本身也不会自动触发收费配音订单。实际大小和套餐限制以产品为准。
