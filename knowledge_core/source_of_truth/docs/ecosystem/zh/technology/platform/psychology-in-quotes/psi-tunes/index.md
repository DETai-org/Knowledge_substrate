# ΨTunes — 图书与播客

**ΨTunes** 是 [Psychology in Quotes](../index.md) 正在开发的功能，将阅读、收听、书签以及可追溯来源的引文连接起来。

> **状态：** ΨTunes 2.0 正在开发和设备测试中。本页面**不代表正式公开发布**，也不保证当前机器人已经提供所有功能。请以实际应用界面为准。

一本书或一期播客可以拥有文本版本和相应的音频版本。播放器旨在保存准确的位置，让书签和引文能够返回正确的来源。音频已制作完成不等于自动获得完整收听权限。

## 了解功能

- [导入个人文档](import.md)：文件格式、章节检查和语音制作。
- [播客与系列](podcasts.md)：节目、系列和访问权限。
- [收听与书签](listening.md)：播放器、网络中断和继续收听。

个人功能使用与 Telegram 绑定的 DETai Account。导入文本不会自动创建付费订单，也不会自动公开发布材料。最新套餐和权限请查看 [PiQ 官方页面](https://detai-x.com/zh/technology/platform/psychology-in-quotes)。ΨTunes 不是心理治疗、医疗服务或诊断工具。

付费服务采用 [PsyTok](../../../../company-and-economy/psytok.md) 计价。套餐额度与购买的通用余额分别记录。用户购买约定结果及所选版本的访问权。价格依据方案条件确定；使用现有兼容版本本身不会改变已约定价格。永久访问权对应所购语言版本；技术修正不要求重新购买。

## 礼物 {#gifts}

在开发中的 ΨTunes 赠礼流程里，**Pro** 用户可以赠送符合条件的已购或自行上传书籍。系统会检查所选版本和语言是否可赠送。您的访问权保留，收件人获得该版本的永久访问权。仅通过订阅获得的收听权不代表可以赠送书籍；个人上传内容也不会因此发布到公共目录。

打开书籍并选择“赠送书籍”。请输入收件人的 **DETai Account 用户名**，而不是 Telegram 用户名。不知道用户名或对方尚未完成注册时，选择 **“通过链接赠送”**。单独确认后将创建一次性链接，首位激活链接的其他用户获得礼物。请私下把链接交给预定收件人；对方无需预先完成完整注册。

查看条款不会扣除 PsyTok。赠礼价格和赠书额度在确认创建礼物时使用，**创建链接时也一样**，而不是等收件人打开链接后才使用。可从赠礼历史再次复制链接。书籍访问权与祝贺消息可能在不同时间到达。

### 赠书额度与恢复 {#gift-limits}

当前 Pro 模型提供**每周期一次赠书机会**。这不代表免费赠送：创建礼物仍需单独支付 PsyTok。

计数器显示**已使用**而非剩余额度：

| 显示 | 含义 |
| --- | --- |
| 已使用：**0 / 1** | 可以创建一份礼物，价格需另行确认。 |
| 已使用：**1 / 1** | 额度已使用，可付费恢复，或等待下一个 Pro 周期。 |

**“重置赠书额度”**首先打开恢复条款。恢复额度与下一份礼物是**两项分别付费的操作**。例如恢复价格为 30 PsyTok、赠礼价格为 15 PsyTok，则下一份礼物合计需要 45 PsyTok：先确认 30，再单独确认 15。这些是示例金额；应用会在每次确认前显示当前价格。

确认恢复后，计数器回到 **0 / 1**。书籍不会自动发送：请继续选择收件人并确认赠礼。重置不会延长 Pro，也不会把额度转入其他周期。下一个 Pro 周期开始时会提供新的额度，无需另付恢复费用；当前周期的结束日期本身并不保证订阅续期。

余额不足时无法确认操作。如果支付后未收到响应，请先刷新状态并查看历史，而不是再次付款。余额与扣款的一般规则见 [PsyTok](../../../../company-and-economy/psytok.md)。
