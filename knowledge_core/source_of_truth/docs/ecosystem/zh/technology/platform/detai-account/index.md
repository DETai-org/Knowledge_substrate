# DETai Account

DETai Account 是 DETai 生态系统的统一账号。网站账户中心和 Telegram 上的 DETai Hub 是同一账号的两个界面。它将个人资料与正在使用的产品、订阅、礼物和成就关联起来；每个产品保留自己的使用和权限规则。

完整的 [Account 指南（俄语原版）](/ru/technology/platform/detai-account/)包含个人资料、安全、产品与订阅、支付与钱包、礼物与成就以及已连接应用。[Platform DETai 概览](/ru/technology/platform/)和[产品目录](/ru/brand-and-communications/product-market/product-catalog/)说明各项服务的关系。接入另一个产品不需要另建一份统一身份。

[打开 DETai 账户中心](https://detai-x.com/zh/account) · [打开 DETai Hub](https://t.me/detai_hub_bot)

## 创建账号或登录 {#sign-in}

如果已有 DETai Account，请在账户中心登录，而不是重新注册。没有账号时，可在网站创建，或按 DETai Hub 的提示操作。浏览公开引文目录不需要账号。

## 将 Telegram 绑定到现有账号 {#connect-telegram}

1. 登录 [DETai 个人资料](https://detai-x.com/zh/account/profile)，选择绑定 Telegram。
2. 使用与 PiQ 相同的 Telegram 账号打开链接，并在 DETai Hub 中确认绑定。
3. 返回 PiQ，或从机器人重新打开 ΨTunes。如 PiQ 提供检查绑定状态的选项，请选择它。

仅登录网站或打开 Hub 不等于完成绑定。如果机器人未识别你的账号，请先检查使用的 Telegram 账号，再考虑注册。请勿分享一次性链接或验证码。

## 更换头像 {#profile-photo}

打开 [DETai 个人资料](https://detai-x.com/zh/account/profile)，在头像区域上传或更换图片，调整裁剪并保存。该图片属于 DETai Account，与 Telegram 头像分开。已接入的界面可以将它显示为 DETai 头像；头像是否公开由单独的隐私设置控制。

## 自助删除账号 {#delete-account}

在账户中心打开**安全**，选择删除账号。系统首先检查是否可以删除，并显示阻止删除的相关义务。确认时需要填写准确的 DETai 用户名；如果设置了密码，还需输入当前密码，并确认会失去购买内容、订阅和剩余 PsyTok 的使用权限。没有密码的账号可能需要重新通过身份提供方登录。

请求已受理与删除已完成是不同状态，请以界面显示的结果为准。只要账号与 Team OS 仍有保留的关联，就会阻止自助删除，包括已离队成员或个人工作空间账号；参见 [Team OS 规则（俄语）](/ru/management-layer/team-os/access/#account-deletion)。已连接产品也会检查未完成的操作和保留数据。

删除账号不等于退款。付款和工作历史、产品材料及已送达的消息可能保留。详细边界见[完整删除指南（俄语）](/ru/technology/platform/detai-account/security/#delete-account)。
