# DETai Account

DETai Account 是 DETai 生态系统的统一账号。网站账户中心和 Telegram 上的 DETai Hub 都访问同一个账号。PiQ 订阅决定产品功能权限；使用 ΨTunes 不需要另建账号。

[打开 DETai 账户中心](https://detai-x.com/zh/account) · [打开 DETai Hub](https://t.me/detai_hub_bot)

## 创建账号或登录 {#sign-in}

如果已有 DETai Account，请在账户中心登录，而不是重新注册。没有账号时，可在网站创建，或按 DETai Hub 的提示操作。浏览公开引文目录不需要账号。

## 将 Telegram 绑定到现有账号 {#connect-telegram}

1. 登录 [DETai 个人资料](https://detai-x.com/zh/account/profile)，选择绑定 Telegram。
2. 使用与 PiQ 相同的 Telegram 账号打开链接，并在 DETai Hub 中确认绑定。
3. 返回 PiQ，或从机器人重新打开 ΨTunes。如 PiQ 提供检查绑定状态的选项，请选择它。

仅登录网站或打开 Hub 不等于完成绑定。如果机器人未识别你的账号，请先检查使用的 Telegram 账号，再考虑注册。请勿分享一次性链接或验证码。

## 更换头像 {#profile-photo}

打开 [DETai 个人资料](https://detai-x.com/zh/account/profile)，在头像区域上传或更换图片，调整裁剪并保存。该图片属于 DETai Account，与 Telegram 头像分开。已接入的界面可以将它显示为 DETai 头像；头像是否公开由单独的隐私设置控制。
