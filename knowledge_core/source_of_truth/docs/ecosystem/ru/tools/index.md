# Tools

**Tools — справочник средств работы и руководств по их использованию в DETai.**
Он помогает выбрать подходящее средство для задачи, настроить его и понять
договорённости о совместной работе.

## Место в экосистеме

Инструменты применяются в обоих кластерах, управлении и сквозных доменах.
Отдельный пункт Tools в меню организует практическую справку; он не обозначает
ещё один кластер или самостоятельный обеспечивающий уровень.

[Infrastructure](../infrastructure/index.md) предоставляет общие системы
и среды исполнения. Tools объясняет работу с конкретными средствами — например,
редактором, GitHub или ChatGPT. Выбор инструмента, доступы и поддержка согласуются
с ответственными за соответствующую работу.

[Onboarding](../onboarding/index.md) обращается к этим руководствам по мере
появления реальной задачи. Общая картина остаётся на странице
[«Экосистема DETai»](../ecosystem/index.md).

## Руководства по задачам

| Что нужно сделать | Где искать описание |
|---|---|
| Организовать задачи, роли, заметки и рабочие итоги | [Team OS](../management-layer/team-os/index.md) и [его интерфейс в ChatGPT](codex/team-os-mcp.md) |
| Работать с кодом, версиями и совместными изменениями | [GitHub](github/index.md) |
| Работать с AI и агентами | [Codex / GPT](codex/index.md) |
| Подготовить локальную среду редактирования | [VS Code](vs-code/index.md) |
| Разобраться в конкретной интеграции или другом инструменте | Соответствующая инструкция в этом разделе |

Наличие инструкции означает, что инструмент описан в базе знаний. Текущий набор
используемых средств и доступы определяются задачей и договорённостями команды.

## Когда появляется проект разработки

Настройка инструмента сама по себе не создаёт новый проект. Если команда решает
создать и поддерживать собственную интеграцию, автоматизацию или другой результат,
у такой работы появляются назначение, ответственный и план развития.

Её место определяется областью ответственности: например, общая инфраструктурная
система относится к Infrastructure, а развитие управления — к Management.
[Эшелон E3](../technology/logic-of-echelons.md) описывает обеспечивающий вклад
проекта; он не переносит все инструменты в Platform DETai автоматически.
