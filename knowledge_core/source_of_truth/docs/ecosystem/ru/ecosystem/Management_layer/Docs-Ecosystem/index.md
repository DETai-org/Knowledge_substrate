# Governance документации

> **Текущий предметный вход:** [система знаний](../../../knowledge/index.md). Эта страница остаётся обзором documentation governance внутри Knowledge System.

Этот раздел определяет, как Knowledge Substrate организует, показывает и связывает знания экосистемы DETai для людей и агентов.

Общий вход в систему знаний находится в разделе [Knowledge, Delivery и Agent Interface](../../../knowledge/index.md). Эта страница объединяет стандарты управления документацией и не является отдельной верхнеуровневой системой.

Главное архитектурное решение: предметная навигация строится по системам и доменам, а функция, статус и нормативная сила документа показываются через видимые метаданные.

Основные документы:

- [Политика metadata документов](document_metadata_policy.md);
- [Реестр metadata schemas](metadata_schema_registry.md);
- [Функции документов](functions_of_documents.md);
- [Документационная архитектура экосистемы](documentation-architecture.md).
