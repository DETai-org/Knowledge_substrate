# Architecture & Logic

Здесь хранятся документы, которые объясняют **строение экосистемы DETai**, распределение ответственности и логику перехода от миссии к решениям и исполнению.

## Основные документы

- [Operating Model DETai](operating-model-detai.md) — обзорная карта для участника команды: сущности, слои, домены, решения, потоки ценности и источники знания.
- [Распределённая архитектура управления](distributed_management_architecture.md) — принципы гибридного управления экосистемой и границы доменных полномочий.
- [Уровни работы](levels-work.md) — переход от концептуального уровня к координации и исполнению.
- [Docs as Executable Interface for Agents](docs-as-executable-interface-for-agents.md) — роль документации как рабочего интерфейса между людьми и AI-агентами.

Operating Model служит входной точкой. Остальные документы раскрывают отдельные механизмы подробнее и не должны заново определять базовые сущности DET, DETai, Platform DETai и U.L.I.
