# GPT Prompt Engine

**GPT Prompt Engine — приостановленный внутренний технический проект с [собственным репозиторием](https://github.com/DETai-org/gpt_prompt_engine).**

Проект предназначен для генерации и сборки промтов на основе нескольких уровней входных данных: глобальных настроек, кастомных параметров, пользовательских и канальных промтов. Архитектурная гипотеза предполагает модульность, overrides, скриптовые преобразования и повторное использование разными системами.

## Место в Platform DETai

GPT Prompt Engine создаёт внутреннюю technical capability и технологический ресурс для других проектов. Он не является самостоятельным внешним продуктом и не требует отдельного пользовательского ценностного предложения, пока не предлагается внешней аудитории как поддерживаемая самостоятельная ценность.

Сейчас owning repository существует, но активный производственный цикл и назначенный владелец не подтверждены. Поэтому проект находится в Dormant Projects, а не в R&D и не среди действующих внутренних технологий.

## Условие возобновления

Нужно назначить владельца, проверить состояние репозитория и потребителей, обновить Project Intent и запустить новый производственный цикл U.L.I. После этого проект возвращается в раздел активных внутренних технологий.
