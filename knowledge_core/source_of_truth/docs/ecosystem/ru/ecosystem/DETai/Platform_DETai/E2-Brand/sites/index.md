# Sites

**`sites` — публичный web-слой экосистемы DETai: набор Next.js-поверхностей, через которые экосистема объясняет и показывает себя, доставляет пользовательские маршруты и связывает бренд, людей, знания и продукты.**

В репозитории находятся:

- `detai-site` — основной профессиональный сайт экосистемы DETai;
- `personal-site` — персональный сайт Антона Колхонена.

Технический источник: [DETai-org/sites](https://github.com/DETai-org/sites).

## Роль основного сайта

Основной сайт выполняет несколько функций одновременно:

1. **объясняет** устойчивую суть DET, DETai и AI-усиленной психотерапии простым языком;
2. **показывает** взаимосвязи через визуальные и интерактивные модели;
3. служит **витриной** бренда, продуктов, проектов и команды;
4. маршрутизирует разные аудитории к нужному уровню глубины;
5. связывает публичные страницы с Knowledge Substrate, научными публикациями и в дальнейшем с полным веб-корпусом книги;
6. формирует ясную семантическую структуру для поисковых и AI-систем.

Пользовательский путь строится по формуле:

> Увидел → заинтересовался → понял взаимосвязи → нашёл свой маршрут → попробовал продукт, углубился в знания или присоединился.

## Граница сайта и документации

Сайт не копирует полные нормативные и операционные документы. Он создаёт их публичную интерпретацию:

- понятный текст;
- визуальную карту;
- интерактивную схему;
- краткий цикл создания ценности;
- маршрут к подробному версионному документу в `docs`.

Knowledge Substrate остаётся источником полных объяснений, стандартов и политик. Сайт делает их смысл видимым и привлекательным для внешнего человека.

## Основные смысловые поверхности

| Поверхность | Функция |
|---|---|
| Главная | Показать целое, обещание бренда и маршруты аудиторий |
| DET | Представить самостоятельный психотерапевтический метод и институциональный слой |
| DETai | Объяснить архитектуру всей экосистемы |
| Platform DETai | Показать технологическую платформу, продукты и проекты |
| U.L.I. | Публично объяснить внутренний контур технологического создания без раскрытия чувствительных деталей |
| О нас | Представить команду, фаундерскую роль, ответственность и участие |
| Блог и публикации | Доставлять редакционные и научные материалы, не смешивая их статусы |
| Docs | Давать переход к полной версионной документации |

## Источники истины

- смысловая и нормативная архитектура — Knowledge Substrate;
- тексты и runtime сайта — репозиторий `sites`;
- авторская аргументация и книга — репозиторий авторства и исследований;
- пользовательские и продуктовые данные — внешние runtime-сервисы и базы;
- задачи и текущий прогресс — ClickUp или утверждённая task-система.
