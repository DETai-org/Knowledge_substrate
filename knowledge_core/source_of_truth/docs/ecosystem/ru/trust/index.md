# Trust, Safety, Privacy и Data Governance

Trust System удерживает условия, при которых людям, специалистам и партнёрам можно обоснованно доверять продуктам и процессам DETai. Это не один документ о безопасности и не обещание отсутствия риска, а сквозная система ограничений, проверок, ответственности и наблюдаемости.

## Четыре взаимосвязанные области

- **Safety** — вред, misuse, failure modes, escalation и release gates.
- **Privacy** — прозрачность, основание обработки, минимизация и права человека.
- **Data Governance** — происхождение, качество, доступ, retention, lineage и допустимое повторное использование данных.
- **Product Assurance** — доказуемая готовность конкретной версии к intended use.

## Инварианты

1. AI не становится терапевтом или носителем профессиональной ответственности по умолчанию.
2. Intended use и non-intended use определяются до публичного обещания.
3. Чувствительность данных определяется контекстом, а не только техническим форматом.
4. Human oversight — это назначенная роль и процесс, а не декоративная фраза.
5. Выпуск требует version-specific evidence; общая репутация проекта не заменяет проверку версии.
6. Обратная связь из продукта не меняет метод автоматически.
