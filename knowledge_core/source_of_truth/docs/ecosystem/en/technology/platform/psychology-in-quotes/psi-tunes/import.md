# Import a book or podcast

[← ΨTunes](index.md)

**Importing** creates a personal text edition from a document you are entitled to use. After extraction, check its title, author, language, chapter order and the beginning and end of the text.

> **Availability:** this workflow belongs to the developing ΨTunes player. Supported formats and limits must be confirmed in the version available to you.

## Files and checks

- **TXT:** verify encoding, paragraphs and headings.
- **FB2 / FB2.ZIP:** verify sections; a ZIP archive must contain a single FB2 document.
- **EPUB:** review the reading order and chapter boundaries.
- **Text-based PDF:** inspect extracted paragraphs, columns and tables. A scan without a text layer needs prior text recognition.

## Intended workflow

1. Choose the available import option in your personal library, from the device or via the Telegram bot.
2. Review the extracted edition, metadata and chapters; correct errors before confirmation.
3. Confirm the edition. Changing source text may create a new edition so previous bookmarks remain unambiguous.
4. If narration is available for this account, choose the language and voice, listen to a sample and confirm the displayed terms before ordering.
5. Open the audio version once prepared and accessible.

Private imports are not automatically published. Uploading does not by itself authorize a paid narration order. Actual size limits and plan restrictions are shown in the application.

## Orders and existing versions

The result and price are shown before confirmation. Fulfilment may prepare new audio or provide an existing compatible version that may be used for this order. Matching checks include the text, language, translation and audio settings; title and author alone are insufficient. Material changes to the order require the user's agreement.

Order status reflects actual work: checking the material, preparation or access readiness. A ready version can be provided without waiting for another narration run. See [PsyTok](../../../../company-and-economy/psytok.md) for pricing, reservations and charges.
