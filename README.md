# Knowledge_substrate | v0.1 🔰

Этот репозиторий описывает и хранит каноническую структуру знаний и документации экосистемы **DETai**, методологическим ядром которой является психотерапевтический метод **DET**.
Здесь находится исходная база знаний, а также пайплайны и операционные хранилища, которые формируют производные представления данных.

**Knowledge Substrate — это долгоживущая основа.**

Он проектируется так, чтобы:
- жить десятилетиями;
- масштабироваться от небольшой команды к большой экосистеме;
- оставаться понятным новым участникам;
- быть устойчивым к смене технологий и инфраструктуры.

## Навигация по уровням

- **knowledge_core/** — главный контур Knowledge Core с описанием стадий работы и их взаимосвязи.
- **README в корне** — внешний обзор репозитория и ссылка на подробную схему в Knowledge Core.

Для детальной схемы и архитектурной логики см. `knowledge_core/README.md`.
